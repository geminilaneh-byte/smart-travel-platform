# Immersive Frontend

1. Preserve server-rendered semantic content and a complete non-WebGL journey.
2. Define a storyboard and measurable user outcome before adding animation.
3. Lazy-load scene code/assets after capability checks; compress glTF textures and media.
4. Provide poster/video fallback and respect reduced motion, keyboard and screen readers.
5. Keep search and checkout independent from canvas.
6. Measure LCP, INP, CLS, memory, GPU failure and mobile data cost.
7. Test low-end mobile, RTL/LTR, slow network and WebGL loss.
8. Remove visual effects that violate the performance budget.
